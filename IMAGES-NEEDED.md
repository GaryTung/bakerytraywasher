## Workflow for Replacing a Placeholder

1. Source/shoot the image to spec
2. Optimize: resize to recommended dimensions, convert to WebP, target <200KB
3. Save to the specified path in `public/images/`
4. Find the `<ImagePlaceholder>` instance in the relevant `.astro` file
5. Add `src="/images/your-image.webp"` prop:

   ```astro
   <ImagePlaceholder
     src="/images/jd-3-hero.webp"
     alt="V-TAI JD-3 bakery tray washer"
     ratio="16/9"
   />
   ```

6. Test in dev mode (`npm run dev`)
7. Commit and push — Cloudflare Pages auto-deploys

## Image Style Guide

- **Color palette**: warm bakery brown (#8B5A2B), cream (#FAF5EB), bakery navy (#1E3A5F)
- **Lighting**: warm, natural where possible; avoid clinical/sterile lighting
- **People**: include real-looking bakery owners and operators where appropriate; avoid generic stock photo people
- **Product shots**: studio quality, white or cream background, slight shadow
- **Lifestyle shots**: authentic working kitchens, not over-styled
- **Diagrams**: clean, vector-style, brand-colored
- **Aspect ratios**: 16:9 for heroes and content blocks, 4:3 for product shots, 1:1 for thumbnails and icons
